# 05 — Control Flow in C++

Control flow determines the order in which statements execute in a C++ program. By default, statements execute from top to bottom, but control flow statements allow us to make decisions and execute different blocks of code depending on conditions.

## Topics Covered

### 1. Conditionals

Conditional statements allow a program to make decisions.

| File | Concept |
|---|---|
| `if_statement.cpp` | Execute code when a condition is true |
| `if_else.cpp` | Choose between two alternatives |
| `else_if.cpp` | Check multiple conditions |
| `nested_if.cpp` | Place an `if` statement inside another `if` statement |
| `switch_statement.cpp` | Select an execution path based on a value |

## Learning Objectives

By completing this module, you should be able to:

- Understand how conditions control program execution.
- Use comparison and logical operators in conditions.
- Write `if`, `if-else`, and `else-if` statements.
- Understand and implement nested conditional statements.
- Use `switch` statements to handle multiple cases.
- Choose an appropriate conditional structure for a problem.

## How to Run

Compile a file using `g++`:

```bash
g++ conditionals/if_statement.cpp -o if_statement
```

Run on Windows:

```bash
.\if_statement.exe
```

Run on Linux:

```bash
./if_statement
```
